# Состояние этапов 0–3

Дата: 2026-09-30.

## Выполнено

- Созданы Android-проект, приватный GitHub-репозиторий и доска с семью Issues; проект зарегистрирован в AgentPulse.
- Собран APK-прототип на `RemoteViews`. Владелец подтвердил на Realme/Android 16 скролл, checkbox, Refresh и resize. Подложка затем изменена с `#99000000` на `#CC000000`.
- Добавлены выбор локального Vault через SAF, сохранение URI permission, фоновый обход Markdown, настраиваемый точный тег и парсер синтаксиса Tasks. Владелец подтвердил, что первый полный обход примерно за минуту нашёл задачу.
- Исправлена пустая обратная связь долгого обхода: экран теперь показывает количество файлов, задач, время и имя файла. Ошибка закрыта регрессионным тестом; реальная проверка нового статуса на устройстве не зафиксирована.
- Добавлен постоянный локальный индекс по ID, времени изменения и размеру файла. Неизменившиеся файлы повторно не читаются; ошибки чтения не удаляют их задачи из индекса. Индекс хранится во внутренней памяти Android-приложения; системный backup отключён.
- Agenda в чистой модели группирует задачи по Scheduled → Due → Start, помещает в «Просрочено» только при Due < today, показывает «Без даты» и горизонт 14 дней. Виджет пока показывает mock-задачи.

## Проверки

`gradlew.bat testDebugUnitTest assembleDebug` завершился успешно; 27 unit-тестов без ошибок и падений. APK `artifacts/vault-index-preview.apk`: versionCode 5, minSdk 26, targetSdk 36, без INTERNET permission. Исходные Kotlin-файлы короче 500 строк. Контрольные суммы и ограничения записаны в `artifacts/index-verification.md`.

Владелец сообщил «всё ок» после сборки индекса и 2026-10-01 явно подтвердил: «этап 3 принят, продолжаем работу». Точные числа «заново/из индекса» на Realme в журнале пока не зафиксированы. Покрытие 80% ещё не измерено. Не выдавать эти пункты за подтверждённые.

Безопасная запись Markdown, стандартные статусы/повторения Tasks, локальный журнал действий и Undo. Перед подключением записи к виджету проверить защиту broadcast-действий от внешнего вызова.
