# TaskManagerWiget

Android-виджет задач из локального Obsidian Vault. Виджет показывает agenda с прокруткой, позволяет отметить задачу, обновить список и открыть исходную заметку. Приложение служит для выбора Vault, настройки тега и внешнего вида, просмотра журнала и Undo.

**Текущий статус:** владелец принял APK-кандидат (`artifacts/taskmanager-widget-candidate.apk`, локальный файл вне Git) на Realme/Android 16 и разрешил коммит и push. Пройдены 94 Android/JVM теста, 4 Python теста, сборка и lint; общее покрытие строк — 927/1141 (81,2%). Проверены checkbox/Undo, deep link, прокрутка, размеры, Refresh после внешней правки и доступ после перезапуска; два скриншота сохранены локально и не публикуются из-за названий личных задач. Цвет заголовка задачи зависит от Start/Scheduled/Due, а сообщение «Обновлено» скрывается через 5 секунд. Чистая установка и восстановление SAF-доступа после reboot проверены на Realme. Периодическое задание с флагом `PERSISTED` осталось в системе и успешно обновило индекс при принудительном запуске после reboot; точный автономный 30-минутный интервал не измерялся, поскольку Android вправе откладывать запуск.
