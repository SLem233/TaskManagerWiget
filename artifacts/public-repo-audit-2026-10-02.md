# Аудит публичного GitHub-репозитория — 2026-10-02

Репозиторий: https://github.com/SLem233/TaskManagerWiget. Проверен опубликованный `main`, а не только локальная рабочая папка.

## Результат

В первой опубликованной истории обнаружились три внутренних документа: `TZ-review-2026-09-30.md` и два файла `docs/handoff/`. Они содержали локальные пути, сведения о конфигурации Vault и среде разработки. Дополнительный проход по исходникам нашёл реальное имя Vault в `VaultIdentityTest.kt`; его заменили синтетическим `DemoVault` во всех коммитах `main`. По разрешению владельца эти пути удалены из всей истории `main` через отдельную зеркальную копию Git. Очистка истории завершилась коммитом `b86206b342d00ff9069d1d00a64f4ee34b3dfbfe`; последующие продуктовые коммиты могут сдвинуть HEAD.

После переписывания проверены дерево GitHub, список его коммитов и содержимое файлов в каждом коммите новой ветки. На GitHub опубликована только ветка `main`; тегов и Releases нет. В опубликованном дереве нет реальных JPEG со снимками задач, APK, `.env`, keystore, контактного блока README и трёх внутренних документов; тесты также не содержат прежнего имени Vault. Два PNG в `artifacts/` содержат синтетические демо-задачи. Оставшийся `C:/Windows/Fonts` в скрипте генерации демо-макетов — общий системный путь, не персональный путь пользователя.

Результат ограничен проверенной веткой `main` и доступным GitHub API. Переписывание истории не стирает возможные сторонние клоны и кэши прежних коммитов. Текущий локальный handoff `docs/handoff/2026-10-01-public-release-reboot.md` не опубликован и не будет включён в коммит.

- `gh repo view` подтвердил публичный репозиторий и ветку `main`.
- `gh api .../git/trees/main?recursive=1` проверил полный набор опубликованных путей.
- `git rev-list` и `git grep` проверили текст всех коммитов новой истории на адреса почты, локальные пути и маркеры контактов.
