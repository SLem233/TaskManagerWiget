## Что реализовано

- В приложении можно выбрать папку Vault через системный SAF и сохранить выданное право доступа.
- Один точный тег задач, по умолчанию #task. Сканирование Markdown идёт в фоновом потоке; .obsidian и .trash исключены.
- Парсер извлекает checkbox, описание, проект, теги, Start/Scheduled/Due/Done, приоритеты и текст правила повторения. Код внутри fenced blocks пропускается.
- Экран показывает количество прочитанных Markdown-файлов, найденных задач и ошибок. Виджет пока отображает тестовые задачи; реальный индекс — следующий этап.
- Подложка виджета изменена с #99000000 на #CC000000; новая подложка ещё не проверена на телефоне.
